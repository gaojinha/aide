## 数据流

```

    │
    ▼
┌─────────────┐
│ 麦克风      │ ──── 驱动层
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 语音识别    │ ──── AI层 (speech_stt)
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 意图理解    │ ──── AI层 (nlp_understand)
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 能力执行    │ ──── API层
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 响应生成    │ ──── AI层 (nlp_generate)
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 语音合成    │ ──── AI层 (speech_tts)
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 扬声器      │ ──── 驱动层
└─────────────┘

    │
    ▼
用户听到回复
```
