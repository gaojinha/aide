# aide 支持的AI模型

## 免费/便宜

### 1. MiniMax (推荐)
- **官网**: https://platform.minimax.cn
- **模型**: abab6.5s-chat
- **价格**: 免费额度多，便宜
- **优点**: 中文好，稳定
- **API Key获取**:
  1. 注册账号
  2. 进入控制台
  3. 创建API Key

### 2. 硅基流动 (SiliconFlow)
- **官网**: https://siliconflow.cn
- **模型**: Qwen/Qwen2.5-7B-Instruct
- **价格**: 免费额度
- **优点**: 接入简单、支持多种模型

### 3. 阿里云百炼
- **官网**: https://www.aliyun.com/product/bailian
- **模型**: qwen-turbo
- **价格**: 有免费额度
- **优点**: 阿里背书，稳定
