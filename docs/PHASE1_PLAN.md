# 阶段一：最小可运行系统

**时间**：0-3月  
**目标**：使用现成开发板快速搭建AI助理系统原型

---

## 重大调整：使用开发板

### 为什么用开发板？

| 对比 | 自研 | 开发板 |
|------|------|--------|
| 难度 | 极高 | 中等 |
| 时间 | 6-12月 | 1-3月 |
| 驱动 | 自己写 | 厂商提供 |
| 风险 | 高 | 低 |

### 推荐开发板：RK3568

| 项目 | 规格 |
|------|------|
| CPU | 8核 (4×A76 + 4×A55) |
| NPU | 1TOPS AI算力 |
| GPU | Mali-G610 |
| 内存 | 8-16GB |
| 接口 | WiFi/蓝牙/USB/HDMI/摄像头 |
| 系统 | Linux/Android |
