# aide - 你的AI助理

> 永远在线、永不拒绝、永远懂你

## 核心理念

**语音为主，动手为辅**
- 说话就能搞定一切
- 不用找菜单点点点
- AI主动记住、主动提醒

## 可以设置什么

| 设置项 | 示例 | 语音命令 |
|--------|------|----------|
| 名字 | 王二狗 | "你叫二狗吧" |
| 唤醒词 | 你好 aide | "以后叫你小爱" |
| 语言 | 中文/英文 | "说英文吧" |
| 语气 | 俏皮/正式 | "正经点" |
| 音量 | 0-100 | "声音调大点" |
| 亮度 | 0-100 | "屏幕亮点" |
| 模式 | 勿扰/自动 | "开勿扰模式" |
| API Key | MiniMax | "设置API Key" |

## 语音能做什么

| 功能 | 示例 |
|------|------|
| **问答聊天** | "今天天气怎么样" |
| **控制设备** | "打开空调"、"关灯" |
| **发消息** | "给老婆发微信说..." |
| **打电话** | "给儿子打电话" |
| **设闹钟** | "明天早上7点叫我" |
| **查信息** | "帮我查下快递到哪了" |
| **播放音乐** | "播放周杰伦的歌" |
| **提醒事项** | "记得下午3点开会" |

## 智能特性

- **记住习惯** - 记得你几点起床、喜欢什么
- **主动提醒** - 下雨带伞、该喝水了
- **人格化** - 有名字、有性格、像朋友

## 技术架构

```
src/
├── ai/           # AI核心 (NLP/Vision/Voice/Model)
├── core/         # 核心系统 (Storage/Security/Config)
├── driver/       # 硬件驱动 (Network/Camera/Sensor)
└── ui/           # 用户界面
```

## 快速开始

```bash
# 编译
mkdir build && cd build
cmake ..
make

# 运行
./aide
```
