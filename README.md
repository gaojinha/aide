# aide - 你的AI助理

> 永远在线、永不拒绝、永远懂你

## 核心理念

**语音为主，动手为辅**
- 说话就能搞定一切
- 不用找菜单点点点
- AI主动记住、主动提醒

---

## 可以设置什么

| 设置项 | 示例 | 语音命令 |
|--------|------|----------|
| **名字** | 王二狗 | "你叫二狗吧" |
| **唤醒词** | 你好 aide | "以后叫我" |
| **语言** | 中文/英文 | "说英文吧" |
| **语气** | 俏皮/正式 | "正经点" |
| **音量** | 0-100 | "声音调大点" |
| **亮度** | 0-100 | "屏幕亮点" |
| **模式** | 勿扰/自动 | "开勿扰模式" |
| **API Key** | MiniMax | "设置API Key" |

## 语音能做什么

### 📞 电话短信
- "给老婆打电话"
- "给儿子发短信说..."
- "接听电话"
- "挂断电话"

### 💬 社交消息
- "发微信给张三：晚上几点回家"
- "看看谁给我发消息了"
- "回复老板：收到"

### 🌐 信息查询
- "今天天气怎么样"
- "帮我查下快递到哪了"
- "现在几点"
- "明天有雨吗"
- "帮我搜一下附近好吃的"

### 🎵 娱乐
- "播放周杰伦的歌"
- "暂停"
- "下一首"
- "声音调大点"

### ⏰ 日程提醒
- "明天早上7点叫我起床"
- "下午3点提醒我开会"
- "一小时后提醒我喝水"

### 🏠 智能家居
- "把灯打开"
- "空调调到26度"
- "关门"
- "打开窗帘"

### 🧾 生活服务
- "帮我叫出租车"
- "订外卖，要宫保鸡丁"
- "查下今天有什么电影"

### 🧮 实用工具
- "计算一下 123 乘以 456"
- "帮我记一下：老婆生日是12月1号"
- "提醒我岳父下个月生日"

### 💬 聊天陪伴
- "今天心情不好"
- "给我讲个笑话"
- "你觉得我该买那个手机"
- "陪我聊聊天"

## 智能特性

### 🧠 记住习惯
- 记得你几点起床
- 记得你爱吃什么
- 记得你下班时间
- 越用越懂你

### ⏰ 主动提醒
- "要下雨了，记得带伞"
- "该喝水了"
- "你儿子快放学了"
- "别忘了带钥匙"

### 👤 人格化
- 有名字：王二狗
- 有性格：稳重幽默
- 像朋友一样相处

## 技术架构

```
src/
├── ai/           # AI核心
│   ├── nlp/      # 自然语言理解
│   ├── vision/   # 视觉识别
│   ├── voice/     # 语音识别/合成
│   ├── model/    # 大模型(本地+云端)
│   ├── memory/    # 用户记忆
│   └── personality.c  # 人格化
├── core/         # 核心系统
│   ├── storage/  # 本地存储
│   ├── security/ # 安全加密
│   ├── config/   # 配置管理
│   └── log/     # 日志系统
├── driver/       # 硬件驱动
│   ├── network/  # WiFi/4G
│   ├── camera/   # 摄像头
│   └── sensor/   # 传感器
└── ui/           # 用户界面
```

# 编译

make

# 运行
./aide
